# Conclusion

Congratulations! You have completed all the scenarios of the Cisco Secure
Firewall SD-WAN hands-on lab.

In this session you have:

- Deployed a hub-and-spoke SD-WAN topology using the SD-WAN Wizard in FMC
- Auto-generated static VTIs on spokes and added them to a Security Zone
- Configured BGP overlay routing and redistributed Static / OSPF / EIGRP routes
- Expanded the deployment to add Hub-side networks and additional branches
- Configured dual-ISP branches with ECMP zones for load balancing
- Resolved an overlapping branch network using Pre-encryption NAT
- Applied geolocation-based controls to Remote Access VPN
